A tiny stack virtual machine for the [make.fun bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122), written from scratch: it runs every `program.bin` on its `input.bin` and answers with exactly the bytes the program prints and the exit code it ends with, including all eleven traps. Run with `node main.ts` (Node 22, stdlib only, deterministic).
